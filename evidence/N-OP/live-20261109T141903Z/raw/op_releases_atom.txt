    <content type="html">&lt;h2&gt;Overview&lt;/h2&gt;
&lt;div class=&quot;markdown-alert markdown-alert-note&quot;&gt;&lt;p class=&quot;markdown-alert-title&quot;&gt;&lt;svg data-component=&quot;Octicon&quot; class=&quot;octicon octicon-info mr-2&quot; viewBox=&quot;0 0 16 16&quot; version=&quot;1.1&quot; width=&quot;16&quot; height=&quot;16&quot; aria-hidden=&quot;true&quot;&gt;&lt;path d=&quot;M0 8a8 8 0 1 1 16 0A8 8 0 0 1 0 8Zm8-6.5a6.5 6.5 0 1 0 0 13 6.5 6.5 0 0 0 0-13ZM6.5 7.75A.75.75 0 0 1 7.25 7h1a.75.75 0 0 1 .75.75v2.75h.25a.75.75 0 0 1 0 1.5h-2a.75.75 0 0 1 0-1.5h.25v-2h-.25a.75.75 0 0 1-.75-.75ZM8 6a1 1 0 1 1 0-2 1 1 0 0 1 0 2Z&quot;&gt;&lt;/path&gt;&lt;/svg&gt;Note&lt;/p&gt;&lt;p&gt;This is an optional release for all op-supernode operators. It removes op-node&#39;s &lt;code&gt;sequencer.max-safe-lag&lt;/code&gt; option from the virtual nodes, and updates &lt;code&gt;golang.org/x/net&lt;/code&gt; past two advisories that do not affect op-supernode.&lt;/p&gt;
&lt;/div&gt;
&lt;h2&gt;Breaking changes&lt;/h2&gt;
&lt;ul&gt;
&lt;li&gt;&lt;strong&gt;Virtual-node &lt;code&gt;sequencer.max-safe-lag&lt;/code&gt; flags removed&lt;/strong&gt; (&lt;a class=&quot;issue-link js-issue-link&quot; data-error-text=&quot;Failed to load title&quot; data-id=&quot;6085042408&quot; data-permission-text=&quot;Title is private&quot; data-url=&quot;https://github.com/ethereum-optimism/optimism/issues/23738&quot; data-hovercard-type=&quot;pull_request&quot; data-hovercard-url=&quot;/ethereum-optimism/optimism/pull/23738/hovercard&quot; href=&quot;https://github.com/ethereum-optimism/optimism/pull/23738&quot;&gt;#23738&lt;/a&gt;). Sequencing no longer pauses when the unsafe head runs ahead of the safe head. Remove &lt;code&gt;--vn.all.sequencer.max-safe-lag&lt;/code&gt; and &lt;code&gt;--vn.&amp;lt;chainID&amp;gt;.sequencer.max-safe-lag&lt;/code&gt; from the launch configuration before upgrading, because op-supernode rejects them as unknown flags. The &lt;code&gt;OP_SUPERNODE_VN_ALL_SEQUENCER_MAX_SAFE_LAG&lt;/code&gt; and &lt;code&gt;OP_SUPERNODE_VN_&amp;lt;chainID&amp;gt;_SEQUENCER_MAX_SAFE_LAG&lt;/code&gt; environment variables are no longer read. The option was disabled by default, so a supernode that never set it is unaffected.&lt;/li&gt;
&lt;/ul&gt;
&lt;h2&gt;Other changes&lt;/h2&gt;
&lt;ul&gt;
&lt;li&gt;Update &lt;code&gt;golang.org/x/net&lt;/code&gt; to v0.62.0, which fixes &lt;a title=&quot;CVE-2026-78661&quot; data-hovercard-type=&quot;advisory&quot; data-hovercard-url=&quot;/advisories/GHSA-75pg-wvh3-34jr/hovercard&quot; href=&quot;https://github.com/advisories/GHSA-75pg-wvh3-34jr&quot;&gt;CVE-2026-78661&lt;/a&gt; and &lt;a title=&quot;CVE-2026-97045&quot; data-hovercard-type=&quot;advisory&quot; data-hovercard-url=&quot;/advisories/GHSA-vwcj-r8v9-p53f/hovercard&quot; href=&quot;https://github.com/advisories/GHSA-vwcj-r8v9-p53f&quot;&gt;CVE-2026-97045&lt;/a&gt; (&lt;a class=&quot;issue-link js-issue-link&quot; data-error-text=&quot;Failed to load title&quot; data-id=&quot;6073555873&quot; data-permission-text=&quot;Title is private&quot; data-url=&quot;https://github.com/ethereum-optimism/optimism/issues/23728&quot; data-hovercard-type=&quot;pull_request&quot; data-hovercard-url=&quot;/ethereum-optimism/optimism/pull/23728/hovercard&quot; href=&quot;https://github.com/ethereum-optimism/optimism/pull/23728&quot;&gt;#23728&lt;/a&gt;). Both are in the module&#39;s &lt;code&gt;html&lt;/code&gt; package, which op-supernode does not use, so earlier releases were not affected; the update clears vulnerability-scanner findings against the module.&lt;/li&gt;
&lt;/ul&gt;

&lt;/div&gt;
&lt;h2&gt;Breaking changes&lt;/h2&gt;
&lt;ul&gt;
&lt;li&gt;&lt;strong&gt;&lt;code&gt;--sequencer.max-safe-lag&lt;/code&gt; removed&lt;/strong&gt; (&lt;a class=&quot;issue-link js-issue-link&quot; data-error-text=&quot;Failed to load title&quot; data-id=&quot;6085042408&quot; data-permission-text=&quot;Title is private&quot; data-url=&quot;https://github.com/ethereum-optimism/optimism/issues/23738&quot; data-hovercard-type=&quot;pull_request&quot; data-hovercard-url=&quot;/ethereum-optimism/optimism/pull/23738/hovercard&quot; href=&quot;https://github.com/ethereum-optimism/optimism/pull/23738&quot;&gt;#23738&lt;/a&gt;). The sequencer no longer pauses block production when the safe head falls behind the unsafe head. op-node now refuses to start with &lt;code&gt;--sequencer.max-safe-lag&lt;/code&gt;, so remove it from your launch configuration before upgrading. A leftover &lt;code&gt;OP_NODE_SEQUENCER_MAX_SAFE_LAG&lt;/code&gt; is ignored, with an &lt;code&gt;Unknown env var&lt;/code&gt; warning at startup.&lt;/li&gt;
&lt;li&gt;&lt;strong&gt;Built-in Holesky L1 chain config removed&lt;/strong&gt; (&lt;a class=&quot;issue-link js-issue-link&quot; data-error-text=&quot;Failed to load title&quot; data-id=&quot;5961924649&quot; data-permission-text=&quot;Title is private&quot; data-url=&quot;https://github.com/ethereum-optimism/optimism/issues/23554&quot; data-hovercard-type=&quot;pull_request&quot; data-hovercard-url=&quot;/ethereum-optimism/optimism/pull/23554/hovercard&quot; href=&quot;https://github.com/ethereum-optimism/optimism/pull/23554&quot;&gt;#23554&lt;/a&gt;). Holesky has shut down. An op-node whose L1 is Holesky now fails to start unless it is given the L1 chain config with &lt;code&gt;--rollup.l1-chain-config&lt;/code&gt;, like any other L1 without a built-in config. The built-in configs for Ethereum Mainnet, Sepolia and Hoodi are unchanged.&lt;/li&gt;
&lt;/ul&gt;
&lt;h2&gt;Other changes&lt;/h2&gt;
&lt;ul&gt;
&lt;li&gt;&lt;code&gt;github.com/andybalholm/brotli&lt;/code&gt; is updated to v1.2.7 for &lt;a title=&quot;CVE-2026-111497&quot; data-hovercard-type=&quot;advisory&quot; data-hovercard-url=&quot;/advisories/GHSA-9v8h-qqgm-4m35/hovercard&quot; href=&quot;https://github.com/advisories/GHSA-9v8h-qqgm-4m35&quot;&gt;CVE-2026-111497&lt;/a&gt;. Go&#39;s bounds checks already kept op-node memory-safe, so it was not exposed. Malformed brotli channels are now rejected earlier, and derivation results are unchanged (&lt;a class=&quot;issue-link js-issue-link&quot; data-error-text=&quot;Failed to load title&quot; data-id=&quot;6062582583&quot; data-permission-text=&quot;Title is private&quot; data-url=&quot;https://github.com/ethereum-optimism/optimism/issues/23689&quot; data-hovercard-type=&quot;pull_request&quot; data-hovercard-url=&quot;/ethereum-optimism/optimism/pull/23689/hovercard&quot; href=&quot;https://github.com/ethereum-optimism/optimism/pull/23689&quot;&gt;#23689&lt;/a&gt;)&lt;/li&gt;
&lt;/ul&gt;
