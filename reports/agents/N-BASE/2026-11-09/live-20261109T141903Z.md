## 为什么可能成立（值得跟踪的机制）

- Aerodrome 是 Base 上池数量与费用权利最集中的 DEX 之一（29,931 个池），新池以克隆方式指向单一 implementation：**只要 implementation 被替换，所有新池的 Swap/费用/权限规则会整体改变**，而池地址不变。把 `implementation()` 与实现地址的代码哈希列入每日监控，可在规则变更当天就发现，而不是从价格异常反推。
- 最新两个池都是 `stable=false` 的波动池（默认 0.30% 费率；`getFee(pool)` 调用未返回，池级 customFee 未确认）。新池 + 默认费率 + 包装资产是后续专项做容量/报价的正常候选，但本岗位不计算收益。
- 工厂克隆模式也意味着"新池身份"核验应统一按：工厂 `isPool` + 池 `factory()` + 克隆目标 implementation + token program/代币合约，而不是只看池地址是否新。
