## 2. 为什么可能成立 / 为什么仍不成立

- **机制上**：上一轮的排除逻辑是“文档只说明借款人买入还债，没有公众赎回”，但链上确实存在公共 PSM。因此原假设的证据基础被纠正——现在应写成“**赎回出口存在，但赎回费 2%**”，而不是“没有出口”。
- **经济上仍不成立**：PSM 赎回方向 2% 费用 → 兑付价 0.98 USDT/lisUSD。本轮可核验的 DEX 买入价（1000 USDT→999.606 lisUSD，成本 1.000394）甚至高于 1.0；聚合器最优展示价 0.9979 也只有 0.21% 折价。**折价 < 2% + gas**，无论按哪个价都亏损。
- **可执行例子（1000 单位，估算非成交）**：Pancake V3 买入 999.605960 lisUSD → PSM 赎回 999.605960×0.98 = 979.613841 USDT → **-20.386 USDT**（gas 未计）；若按聚合器最优价 0.9979 买入 → 1002.10 lisUSD → 赎回 982.06 USDT → 约 **-17.9 USDT**。仍为负。
- **容量**：赎回单日 500,000 USDT、总额 759,188.56 USDT；铸币受 PSM 7.97M lisUSD 库存限制。容量足够做小额测试，但费用结构决定没有正差。

## 4. 还缺什么（覆盖缺口）

- **未做 PSM buy()/sell() 的只读模拟或成交验证**：费用/限额来自源码公式+链上参数，不是实际结算。bsc-dataseed 的 stateOverride 支持未验证。
- **未测大额赎回真实到账**：接近 500,000 USDT/日时 VaultManager 从 VenusAdapter 逐适配器提取的流动性与 tx 内行为未验证（vUSDT getCash 虽是 26.27M USDT，但合约级总上限 759,188.56）。
- **深池 `0x8b94363f…` 无 quoter**：DEX/工厂身份未核验，聚合器 0.9979 不能当可执行价；这是“折价是否真实存在”的关键缺口。
- **30 天规则变更未遍历**：未查 buyFee/sellFee/dailyLimit/暂停在 2026-10-10–2026-11-09 的变更（PSM 有 SetBuyFee/SetSellFee/SetDailyLimit 事件可分段扫）。
- **7 天活动未覆盖**：未读 PSM BuyToken/SellToken 事件与 DEX 成交，无法判断折价是否曾覆盖 2% 费用。
- **lisUSD token 权限未读**：转账税/黑名单/暂停开关；LisUSDPoolSet/EarnPool 细节未核。
- **请求数超限**：本岗位外部请求约 **117 次**（含 3 次 raw.githubusercontent SSL 重试），超出 ≤80 建议上限；原因是需从仓库部署脚本定位 PSM 再补链上字段，下轮必须压缩。
