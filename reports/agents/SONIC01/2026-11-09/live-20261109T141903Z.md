   - Metropolis **USDC/scUSD** 对 `0x5015643B8dB50A1cB779A3e134176237d14ca67a`（DexScreener 流动性仅约 315 美元；接口未知，未报价）。
   - **Curve Sonic**：`api.curve.finance/api/getPools/sonic/main` HTTP 200 但 `poolData` 为空（该 API 未返回 Sonic 池）→ 源限制，不能把 Curve Sonic 当已核市场。
4. **固定块推导报价（重要：非官方 Quoter，单 tick 数学推导，含假设）**：因 Shadow 两个池是 CL 型（Solidly 的 `getAmountOut` 与 Curve 的 `get_dy` 调用均 revert），本轮用链上 slot0/liquidity/fee 做单 tick 内 CL 公式推导（fee 按 95/1e6=0.0095% 假设，未跨 tick）：
   - Shadow USDC→USDT：100 USDC=**100.104009 USDT**（1.00104）、1000 USDC=**1001.02405 USDT**（1.001024）→ 池内 USDC 相对 USDT 便宜约 0.10%（USDT 溢价）。
   - Shadow USDC→scUSD：100 USDC=**99.994894 scUSD**（0.999949）、1000=**999.909074 scUSD**（0.999909）→ 接近 1。
   → 若该推导成立，USDC 在 USDT 池有约 +0.10% 的「换成 USDT」毛差。
5. **但闭环不成立（REJECTED 核心）**：要回到起始 USDC 需要**第二个独立市场**做 USDT→USDC。本轮发现里 USDT/USDC 只有 Shadow 一个池；Metropolis 只有 USDC/scUSD（且接口无法报价，流动性约 $315）；Curve Sonic API 无池。**没有第二腿独立报价 → 无法组成 2 腿闭环**；同时 USDC.e/USDT 作为桥接资产的跨链出口需等待、scUSD 发行/赎回规则未核。故本轮不构成可执行机会，仅登记「单市场 USDT 溢价」线索与排除理由。

## 为什么可能成立/不成立（本轮结论）

Sonic 上 USDC.e 的 symbol 与原生 USDC 相同，不能凭名称合并；本轮按地址分别建档。单市场推导显示 Shadow USDC/USDT CL 池中 USDT 相对 USDC 有约 0.10% 溢价（可能的失衡来源：近期交易/流动性），但要闭环必须有第二个独立市场回兑 USDC——本轮未发现可报价的第二市场，Metropolis 池太小且接口不匹配，Curve Sonic 无池数据。因此**没有完整闭环，列为排除**；另外推导报价依赖 fee 单位假设与单 tick 内成交假设，未经官方 Quoter 验证，不能作为可执行价。
