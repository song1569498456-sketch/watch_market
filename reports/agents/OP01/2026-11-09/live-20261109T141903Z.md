# OP01 本轮报告：OP 稳定币身份/出口分离 + USDC/USDC.e/USDT 同块折价与跨链出口

## 发现什么

1. **三种「USDC/USDT」不是同一权益（链上已核验）**：
   - **原生 USDC** `0x0b2c639c533813f4aa9d7837caf62653d097ff85`：代码 1,852 B 的 Circle 代理（自定义实现槽 `0x7050c9e0…` → impl **`0xded3b9a8dbedc2f9cb725b55d0e686a81e6d06dc`**，23,464 B）；name=USD Coin、symbol=USDC、6 位、paused=false。
   - **USDC.e** `0x7F5c764cBc14f9669B88837ca1490cCa17c31607`：代码 14,725 B，**name/symbol 同样是 USD Coin/USDC**、6 位；`l1Token()`=`0xa0b86991…`（L1 USDC）、`l2Bridge()`=`0x4200…0010`（OP 标准桥，代码 2,055 B）→ 桥接表示，非发行方原生。
   - **USDT** `0x94b008aA00579c1307B0EF2c499aD98a8ce58e58`：代码 6,774 B，name=Tether USD/USDT/6 位；`l1Token()`=`0xdac17f95…`（L1 USDT）、`l2Bridge()`=`0x4200…0010` → 桥接表示。
2. **链上可执行出口只有两类**：① DEX 即卖（唯一 OP 本链即时出口）；② 桥接版走 OP 标准桥回 L1（跨链、需等 L1 证明期，**不是 L2 即时兑付**）。原生 USDC 的发行方赎回是 Circle 场外流程（链上无普通账户赎回函数；burn 仅 minter，沿用上轮源码证据），**链上不可执行**，不计入出口。
3. **同块 DEX 报价（Uniswap V3，fee 100）**：
   - 卖 USDC.e→USDC：1=0.999824、10=9.998241、100=**99.982349**、1000=999.817118（折价约 **0.018%**；池 `0x2ab22ac8…` liquidity=141,118,541,498,271）。
   - 买 USDC→USDC.e：100=**99.997509**（即买 USDC.e 反而溢价，无法用「买折价 USDC.e」闭环）。
   - 卖 USDT→USDC：1=0.998787、10=9.98785、100=**99.876044**（-0.124%）、1000=**996.201373**（-0.380%，冲击）。
   - 买 USDC→USDT：100=**100.098834**（+0.0988%）、1000=**1000.904767**（+0.0905%）。
4. **唯一有毛差的跨链候选（DELAYED）**：用原生 USDC 在 DEX 买入 USDT，1000 USDC→**1000.904767 USDT**（毛 +0.0905%），USDT 是 L1 USDT 的桥接表示，经 OP 标准桥回 L1 可得 L1 USDT（1:1），但需等待 L1 证明/争议窗口（约 7 天量级，本轮未链上核实具体天数）并支付 L2 提款+L1 领取 gas。粗估 L1 领取 ~5-10 万 gas（当前 L1 baseFee≈0.42 gwei）≈ **0.02-0.04 ETH 量级**（约 $0.13-0.2？未用实时 ETH 价假设，标记 estimate）；1000 档毛差约 0.9 USDT，扣估算 gas 后接近零或小幅正，**需资本锁定约 7 天**，故不给净利、只记 DELAYED + 待核成本。**不把它当 L2 即时兑现**。
5. **USDC.e 折价不可闭环（REJECTED）**：卖方向折价仅 0.018%，但买方向是溢价（100 USDC 只得 99.9975 USDC.e），且出口只有 DEX 卖回（损失往返费）或跨链回 L1（gas>折价）；USDT 买方向 0.09% 毛差跨链也仅勉强覆盖估算 gas。

## 为什么可能成立/不成立（本轮结论）

三种资产名称相近但发行/桥接关系不同：原生 USDC 有场外赎回（链上不可执行），USDC.e/USDT 是 L1 资产的规范桥接（唯一协议出口是跨链回 L1，等待 L1 证明期）。DEX 报价显示 USDT 的「买方向」有约 0.09-0.10% 毛差、USDC.e 卖方向约 0.018% 折价，但两者都无法在本链即时闭环：USDC.e 买方向无折价，USDT 需跨链 7 天且 gas 与折价同量级。因此不构成可执行净利，最多是 7 天资金锁定的微小跨链差（DELAYED）。
